## 자산 온도는 상대적인 온도예요

싸다·비싸다는 "가격이 적정한가"를 판정한 게 아니에요. 각 자산을 **자기 지난 20년 흐름**, 그리고 **다른 자산들**과 견준 상대적인 온도예요.
'비싸다'는 평소보다·다른 자산보다 많이 올라 있다는 뜻일 뿐, 떨어진다는 예측이 아니에요. 비싸도 더 오를 수 있고, 싸도 더 내릴 수 있어요.
